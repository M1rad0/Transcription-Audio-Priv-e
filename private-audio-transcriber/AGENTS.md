## Project name

Private Audio Transcriber V1

## Project purpose

This project is a local-first private audio transcription system.

The user uploads an audio file through a local Next.js application. The local backend-for-frontend encrypts the audio, sends it to a custom RunPod Serverless worker, receives two outputs, and displays/exports them.

Expected outputs per job:

- `raw.txt`: raw transcription generated by faster-whisper.
- `modified.txt`: corrected and structured version generated by a lightweight local LLM.
- `result.json`: structured JSON with metadata, segments and cleanup status.

The system is designed to process approximately:

- 120 minutes of audio per day;
- 6 days per week;
- around 52 hours of audio per month.

The goal of V1 is not perfect transcription. The goal is a private, usable, human-reviewable transcription workflow with controlled GPU cost.
